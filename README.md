# The Well-Tempered Matrix

**Linear algebra you can hear, with J. S. Bach as our guide.**

The Well-Tempered Matrix teaches linear algebra, with an emphasis on matrix theory, by turning every idea into sound. Melodies become matrices, and matrices become transformations you can listen to: a reflection plays a melody upside down, another plays it backward, and the two together turn out to be a rotation.

Linear algebra is the common language of nuclear engineering, quantum computing, and the physics of sound. This project starts with music and builds toward all three.

## Why Bach?

Johann Sebastian Bach (1685–1750) composed with patterns. He turned melodies upside down (inversion), played them backward (retrograde), shifted them to new starting pitches (transposition), and combined them against themselves in canons and fugues. These are the same transformations a matrix performs. His music is also in the public domain, so it can be used freely.

## What you will learn

- Vectors and matrices, using notes and melodies as data
- Matrices as transformations: stretching, reflecting, and rotating
- Matrix multiplication as combining transformations, and why order matters
- Determinants, inverses, and singular matrices
- Eigenvalues and eigenvectors, heard as the natural frequencies of vibrating systems
- Later: complex numbers, Fourier analysis, quantum gates, reactor criticality, and random matrix theory

## How to use the notebooks

The notebooks run in **Google Colab**, a free tool that runs Python in a web browser. Nothing needs to be installed.

1. Open a notebook (`.ipynb` file) in this repository.
2. Open it in Colab: go to [colab.research.google.com](https://colab.research.google.com), choose **File → Open notebook → GitHub**, and paste this repository's address.
3. Run the cells from top to bottom by clicking a cell and pressing **Shift + Enter**, or use **Runtime → Run all**.
4. Use headphones or speakers. A ▶ player appears under each cell that makes sound.

**Tip:** predict what you will hear before you press play. Guessing first, even when the guess is wrong, is where the learning happens.
